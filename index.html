Selected work

Portfolio Insight Copilot

A no-cost, static fintech AI demo that explains portfolio moves and helps users build a portfolio from scratch. Investors can add, edit, and delete holdings across a broad U.S. listed ticker universe, compare performance against SPY, QQQ, and SCHD, and run an AI risk review with transparent scoring factors. Less-prominent listed symbols use simulation-backed estimates calibrated from my market simulator, while explanations stay grounded with citations, non-advisory guardrails, and an optional prompt-packet view for interview walkthroughs.

BanditFeed

A live recommendation-system demo that ranks real RSS articles with contextual bandit algorithms. Users tune their interests, read a personalized feed with predicted ranking badges and match scores, open the original articles, and watch every click update the model's beliefs. The app also includes a "Why?" explainer that connects the demo to the recommendation loops behind social feeds, search, and content platforms.

Agent-Based Market Simulator & Strategy Validation Firewall

A from-scratch stock market where the price emerges from thousands of interacting trader-agents — paired with a statistical "firewall" that honestly tests whether a trading strategy has real edge. Across eight strategy families it found none (the correct answer for efficient markets); the one signal that survived is volatility forecasting, competitive with industry-standard models. Pure Python, ~350 tests, tamper-evident result logging. The simulator now also feeds Portfolio Insight Copilot's benchmark and listed-symbol estimate layer, giving the AI demo transparent data provenance instead of unexplained mock values.

  • Python
  • Simulation
  • Applied statistics
  • Data engine

Photon Forge

A browser-based 3D ray-traced light puzzle game built as a computer graphics demo. Players drag optical components onto a Three.js board, rotate the camera, move misplaced optics, solve reflection and color routing puzzles, and build custom sandbox levels with draggable source, target, and wall tools. The project demonstrates ray-segment intersections, reflection vectors, spectral dispersion, filtering, height-layer beam routing, perspective camera controls, and polished first-run onboarding.

  • JavaScript
  • Three.js
  • Computer graphics
  • 3D game UI

Ripple — a wave-interference puzzle

A logic puzzle built on real wave physics: drop emitters and their ripples interfere — reinforcing into bright spots, cancelling into dark ones. Solve each level by placing sources so the pattern lights the right targets and silences the others. Vanilla JS + Canvas; levels are procedurally generated from a known solution, so every puzzle is guaranteed solvable.

  • JavaScript
  • Canvas

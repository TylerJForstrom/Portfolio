Selected work

NYC Real Estate Map: market analytics on 338k real sales

A full-stack market analytics platform built on recorded NYC property sales from NYC Open Data — real prices and dates, no scraped listings. An interactive map clusters tens of thousands of sales with heatmap and neighborhood choropleth layers, and a Market Insights tab answers the buyer's question directly: repeat-sales returns computed from the same property selling twice, price-vs-momentum quadrants, liquidity shifts, and seasonality. All geospatial queries run in PostGIS, and a daily pipeline dedupes records, flags $10 deed transfers, and catches outliers with robust statistics. The demo serves a real 25k-sale snapshot of the full system.

  • FastAPI
  • PostgreSQL / PostGIS
  • React + TypeScript
  • MapLibre GL
  • Data engineering

Plain: a programming language that reads like English

A complete programming language and interpreter built from scratch in pure Python — tokenizer, parser, and runtime. Plain sits between block coding and Python: real typed-out programs in words you already know, with friendly line-numbered errors and a trace mode that narrates code as it runs. The goal is that someone new to coding can solve real interview problems with it; the repo includes 16 solved LeetCode problems written in Plain. The demo site runs the actual interpreter in your browser, with practice problems, searchable docs, and a docs assistant.

  • Python
  • Language design
  • Interpreters
  • WebAssembly (Pyodide)

BanditFeed

A hands-on recommender demo that makes the learning loop visible. BanditFeed ranks real RSS articles with contextual bandit algorithms, shows why each article was recommended, and updates its beliefs as users click or skip items. It is meant to make the same explore-vs-recommend tradeoff behind feeds, search, and content apps feel concrete instead of abstract.

Agent-Based Market Simulator & Strategy Validation Firewall

A stock market simulation built from the ground up, where prices come from thousands of trader-agents interacting through an order book. I paired it with a statistical validation layer to test whether strategies actually had edge after costs and walk-forward testing. Most directional strategies failed, which was the honest result; volatility forecasting was the useful signal that held up. The simulator also provides calibration data for Portfolio Insight Copilot.

Photon Forge

A 3D light puzzle game built to make computer graphics concepts playable. Players drag mirrors, prisms, filters, sources, targets, and walls onto a Three.js board, then solve puzzles by routing beams through the scene. Under the hood it uses ray-segment intersections, reflection vectors, color filtering, height-layer beam routing, and camera controls, but the goal is still simple: make the puzzle feel intuitive.

  • JavaScript
  • Three.js
  • Computer graphics

Ripple: a wave-interference puzzle

A small browser puzzle about wave interference. Players place emitters so ripples reinforce the targets they want and cancel the ones they do not. It is built with vanilla JavaScript and Canvas, and the levels are generated from known solutions so every puzzle is solvable instead of randomly unfair.
